📘 智档 · 综合管理系统 使用说明 v3.0

本系统集成了档案、人员、报名三大管理模块，所有数据均采用端到端加密存储，支持云端备份与多用户审核协作。

🔐 登录

  • 项目库码：由管理员分配，每个项目库独立。
  • 用户名 / 密码：由管理员创建，登录后自动读取对应权限。
  • 登录后，系统会从云端同步最新数据，并每10分钟自动检查一次更新。

📂 三大管理系统

点击顶部标签切换：

  • 📁 档案管理系统：管理工程档案信息，支持模糊查找、高级筛选、批量操作。
  • 👥 人员管理系统：管理人员证件、岗位、有效期等信息，支持离职数据过滤。
  • 📋 报名管理系统：管理投标报名项目，自动计算开标倒计时（精确到分钟）。
💡 提示： 三个系统均支持表格单元格 鼠标悬停 显示完整内容，右键单击 弹出浮动框展示全部数据（移动端长按触发）。

🔒 审核协作流程

  • 提交审核：任何有备份权限的用户均可将本地数据提交到审核区，同时生成一个加密版本。
  • 审核处理：拥有审核权限的用户登录后，系统会自动检测待审核数据并弹出提醒（“操作”按钮闪烁红字）。点击“操作 ▾” → “审核”进入审核界面。
  • 版本选择：审核者可选择任一待审核版本，输入该版本的加密密钥（由提交者提供）解密数据。
  • 差异对比：系统会展示本地数据与审核版本的差异表格，审核者可逐项勾选要覆盖的字段。
  • 审核完成：点击“覆盖选中项”或“全部忽略”，审核版本会被标记为已处理。审核通过后，系统会询问是否将当前本地数据（含审核合并结果）正式备份到云端。
  • 正式备份：若选择备份，需输入新的加密密钥，系统将数据加密上传至正式云端，并生成一份 .xlsx 本地备份文件供保存。

☁️ 云端备份与恢复

  • 备份前对比：点击“提交审核”时，系统会先获取云端数据，若存在差异，会弹出对比表格（支持按行勾选），用户可选择以云端覆盖本地或忽略。
  • 加密密钥：备份时需输入自定义密钥（两次确认），该密钥用于解密恢复，请妥善保管。
  • 分片存储：大数据自动分片上传，保证稳定。
  • 恢复：输入备份时的密钥即可解密并覆盖本地数据。

🔎 高级筛选与搜索

  • 模糊查找：在搜索框中输入关键词，系统会自动高亮匹配项。
  • 高级筛选：点击“高级筛选”标题可折叠/展开筛选项，支持多条件组合筛选（如日期区间、价格范围等）。
  • 排序：点击表头可对当前列进行升序/降序排序。

🛠️ 辅助工具（全局顶部栏）

  • 📅 黄历：点击日历图标弹出今日黄历，含宜忌、冲煞、星宿等信息（需联网）。
  • 🧮 日期计算：点击“日期计算”按钮，可快速计算两个日期之间的天数或推算目标日期。

✨ 系统特色功能

  • 人员到期提醒：系统自动检测人员证书有效期，过期或临期会弹出提醒表格。
  • 档案完整性检查：自动检查无合同、无合作协议、无竣工资料（竣工超30天）的档案，并提示。
  • 报名开标提醒：根据开标日期，在开标前3天和7天内分别提醒做书、保证金等。
  • 离职数据过滤：人员系统支持勾选“离职数据”复选框，显示/隐藏备注含“离职”的人员。
  • 数据安全：所有本地数据使用 PBKDF2 + AES-CBC 加密，云端数据使用 AES 加密，密钥由用户掌握。

⚠️ 注意事项

  • 密钥管理：备份/审核密钥请务必牢记，丢失后无法恢复数据。
  • 多设备协作：建议定期提交审核并正式备份，确保云端数据为最新权威版本。
  • 浏览器兼容：推荐使用 Chrome / Edge / Firefox 等现代浏览器。
  • 数据隐私：所有加密操作均在本地完成，云端仅存储密文，服务商无法读取您的数据。
