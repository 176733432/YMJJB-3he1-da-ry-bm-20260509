🔐 登录系统

  1. 打开网页，进入登录界面。
  2. 在「项目库码」输入框中输入管理员分配的库码（密码形式显示）。
  3. 在「用户名」输入框中输入您的账号。
  4. 在「密码」输入框中输入您的密码。
  5. 点击「登录」按钮，或按键盘 Enter 键（输入密码后直接回车）。
  6. 登录成功后，自动进入「档案管理系统」主界面，右上角显示当前用户名。
💡 提示： 如忘记密码请联系管理员重置。

📁 档案管理系统

🔍 查询档案

  1. 在「模糊查找」输入框中输入关键字（如档案号、工程名称、甲方单位、工程地址、项目经理等）。
  2. 系统自动检索并刷新下方表格，匹配的关键词会高亮显示。
  3. 如需清空搜索，点击「清除」按钮。
  4. 点击「查询结果」右侧的「操作 ▾」下拉菜单，可使用更多功能。

🔎 高级筛选

  1. 点击「高级筛选 (实时生效)」标题展开筛选条件面板。
  2. 根据需要填写或选择筛选条件：所属公司、工程类别、使用性质、承包方式、合同价格范围、中标/竣工/签署日期、建筑面积、结构形式、层数以及各文件（中标通知书、合同、合作协议等）的有无。
  3. 所有筛选条件实时生效，表格自动更新。
  4. 点击「清除筛选」可一键重置所有筛选条件。

➕ 新增档案

  1. 点击「操作 ▾」下拉菜单，选择「➕ 新增档案」。
  2. 在弹出的表单中填写工程信息（带 * 的为必填项，工程名称必填）。
  3. 「档案号」若重复系统会提示，并支持自动补全序号（输入年份或带前缀的年份后自动生成后续编号）。
  4. 「开工日期」与「竣工日期」选择后，「总工期」会自动计算（也可手动修改）。
  5. 「合作人」填写后，若系统中已有该合作人的联系电话，会自动填入。
  6. 合同、合作协议、竣工文件各自带有“提示”复选框，勾选后系统会定期检查并提醒缺失情况。
  7. 填写完成后点击「保存」，新增记录即存入本地。

✏️ 编辑档案

  1. 在查询结果表格中，勾选需要编辑的行（可勾选多个）。
  2. 点击「操作 ▾」→「✏️ 编辑」，系统会依次打开编辑窗口。
  3. 修改信息后点击「保存」即可更新。
  4. 也可以直接双击表格中的任意行快速编辑该条记录。

🗑️ 批量删除

  1. 在查询结果表格中勾选需要删除的行。
  2. 点击「操作 ▾」→「🗑️ 批量删除」。
  3. 系统会弹出密码验证窗口，输入登录密码后确认。
  4. 再次确认删除后，所选记录即被移除。

📂 从 EXCEL 导入

  1. 点击「操作 ▾」→「📂 从EXCEL导入」。
  2. 选择本地的 .xlsx 或 .xls 文件。
  3. 系统自动解析并导入，相同档案号的记录会更新，新档案号则新增。
  4. 导入完成后会显示「新增X条，更新X条，无变化X条」的提示。

☁️ 提交审核（普通用户）

  1. 点击「操作 ▾」→「☁️ 提交审核」。
  2. 输入加密密钥（需牢记，审核时需提供此密钥）。
  3. 确认密钥后，数据会提交至审核队列，等待审核者处理。
  4. 提交成功后，审核者端会收到提醒（操作按钮会闪烁）。

🔍 审核（仅审核者可见）

  1. 当有待审核数据时，「操作」按钮会闪烁红色提醒。
  2. 点击「操作 ▾」→「🔍 审核」。
  3. 系统列出所有待审核版本，输入对应的编号选择。
  4. 输入提交者提供的加密密钥，系统解密并对比数据差异。
  5. 差异记录以表格展示，审核者可勾选需要以云端覆盖本地的行，点击「覆盖选中项」；也可选择「全部忽略」保留本地数据。
  6. 本地没有的数据会自动新增，并显示新增明细。
  7. 审核通过后，系统会询问是否立即备份到正式云端，确认后输入备份密钥即可完成同步。

⬇️ 从云端恢复

  1. 点击「操作 ▾」→「⬇️ 从云端恢复」。
  2. 输入备份时使用的随机加密密钥。
  3. 系统会弹出登录密码验证（输入您的登录密码）。
  4. 验证通过后，云端数据将覆盖本地数据（请谨慎操作）。

🔄 手动刷新

  1. 点击系统右上角的「🔄 刷新」按钮（每个系统均有）。
  2. 系统立即从云端拉取最新数据并与本地对比，弹出差异选择窗口（如有）。
  3. 同步完成后显示统计信息（新增、覆盖、未覆盖数量），并展示新增数据明细。

📥 导出数据

  1. 点击「操作 ▾」→「📥 导出全部」可导出所有档案数据。
  2. 点击「📥 导出查询结果」可导出当前查询/筛选后的数据。
  3. 导出前可勾选需要导出的字段，确认后生成 Excel 文件。
⚡ 小技巧： 表格列头点击可排序（升序/降序循环切换）；右键点击任意单元格可查看完整内容（长文本自动弹出）。

👥 人员管理系统

🔍 快速查找

  1. 在「快速查找」输入框中输入姓名、身份证号或备注关键词。
  2. 系统自动过滤并刷新表格，匹配的关键词高亮显示。
  3. 点击「清除」可清空搜索条件。

🔎 高级筛选

  1. 点击「高级筛选」展开面板。
  2. 可按「类别」「岗位」「级别」「注册专业」「所属公司」「社保」「有效期」等条件筛选。
  3. 选择「其他」后可在自定义输入框中填写具体内容，筛选条件实时生效。
  4. 点击「清除筛选」可重置所有条件。

➕ 新增人员

  1. 点击「操作 ▾」→「➕ 新增人员」。
  2. 填写人员信息（姓名必填）。
  3. 填写「姓名」后，若系统中已有同名人员，系统会自动填充身份证、电话、冀时办账号密码等信息。
  4. 填写完成点击「保存」。

✏️ 编辑 / 🗑️ 删除

  1. 勾选需要编辑或删除的行（可多选）。
  2. 点击「操作 ▾」→「✏️ 编辑」或「🗑️ 批量删除」。
  3. 编辑后保存即可更新；删除需登录密码验证。
  4. 双击表格行也可快速编辑。

📂 从 EXCEL 导入

  1. 点击「操作 ▾」→「📂 从EXCEL导入」。
  2. 选择 Excel 文件，系统按身份证+注册号匹配更新，无匹配则新增。
  3. 导入完成后显示更新/新增数量。

🔒 显示冀时办信息

  1. 点击「操作 ▾」→「🔒 显示冀时办信息」。
  2. 输入登录密码验证身份。
  3. 验证通过后，表格中的「联系电话」「冀时办账号」「冀时办密码」列将显示真实内容（原为 ***）。
  4. 再次点击该按钮可隐藏敏感信息。

☁️ 提交审核 / 🔍 审核 / ⬇️ 恢复 / 📥 导出

  1. 操作方式与档案系统完全一致，参考档案系统对应章节。
  2. 「提交审核」需输入加密密钥；「审核」需输入提交者密钥并选择覆盖项。
  3. 「从云端恢复」和「导出」操作同理，均需登录密码验证。
  4. 支持「手动刷新」按钮，强制拉取云端最新数据并对比合并。
📌 注意： 勾选「离职数据」复选框后，备注中含“离职”的人员将显示在表格中，方便查看离职人员信息。

📋 报名管理系统

🔍 快速查找

  1. 在输入框中输入工程名称、委托人、项目经理、资料或备注关键词。
  2. 系统自动检索并刷新表格，匹配项高亮显示。

🔎 高级筛选

  1. 点击「高级筛选」展开。
  2. 可按「所属公司」「是否已至开标日」「保证金」「开标方式」筛选。
  3. 筛选条件实时生效，点击「清除筛选」重置。

➕ 新增 / ✏️ 编辑 / 🗑️ 删除

  1. 点击「操作 ▾」→「➕ 新增报名」。
  2. 填写工程名称（必填）、委托人、项目经理、开标日期等信息。
  3. 「序号」根据所属公司自动生成（如 ZD-2025-001）。
  4. 编辑和删除操作与档案系统类似，勾选后执行，删除需密码验证。
  5. 双击表格行可快速编辑。

📂 从 EXCEL 导入

  1. 点击「操作 ▾」→「📂 从EXCEL导入」。
  2. 选择 Excel 文件，系统按「序号」匹配更新或新增。

📥 导出 / ☁️ 提交审核 / 🔍 审核 / ⬇️ 恢复

  1. 操作方式与档案系统一致，可导出全部或查询结果。
  2. 审核流程相同：普通用户提交审核，审核者审核并备份，差异数据弹窗选择覆盖。
  3. 支持「手动刷新」按钮，实时同步云端最新数据。
📌 注意： 勾选「隐藏已开标项目」后，已开标或已取消投标的项目会自动隐藏，方便聚焦进行中的项目。「开标状态」列动态显示距离开标剩余时间或已开标信息。

📋 操作日志

  1. 操作日志记录了用户在系统中的所有操作（新增、编辑、删除、导入、导出、审核、同步等）。
  2. 日志包含：时间、操作者、操作项目、所属系统、数据详情。
  3. 日志存储在本地浏览器中，按用户名区分，每人独立。
  4. 当日志达到 1900 条时会自动提醒导出备份，超 2000 条自动删除最早记录，确保存储空间合理。
  5. 查看日志的方式请联系管理员获取（通常通过特定入口或咨询管理员）。

🧰 实用工具

📅 今日黄历

  1. 点击页面顶部工具栏的「黄历」按钮。
  2. 系统弹出今日黄历信息，包含公历、农历、生肖、宜忌、冲煞、星宿等详细内容。
  3. 点击「关闭」或右上角 × 关闭窗口。

📆 日期计算

  1. 点击页面顶部工具栏的「日期计算」按钮。
  2. 在弹窗中输入「开始日期」「结束日期」或「相差天数」中的任意两项。
  3. 点击「计算」按钮，系统自动推算第三项。
  4. 点击「清空」可重置所有输入。
  5. 点击「关闭」关闭窗口。
📌 提示： 黄历和日期计算工具均支持在输入框内按 Enter 键快速执行计算或确认。

📌 通用操作提醒

🔐 密码验证
执行敏感操作（删除、恢复、显示敏感信息、查看日志）时需验证登录密码。
☁️ 数据同步机制
登录时、每小时定时、切换系统时以及手动刷新时自动与云端对比。新增数据自动拉取，差异数据弹窗选择覆盖（可逐条勾选）。同步后显示统计信息（新增X条，覆盖X条，未覆盖X条），并展示新增数据明细。
📊 数据统计
每次同步或导入操作后，系统会弹出统计信息，让您清晰了解数据变更情况。
🔄 排序与查看
表格列支持点击排序（升序/降序循环切换）；右键点击单元格可弹出完整内容（适用于长文本）。
